# RADAR Lavoro — prototipo demo

Strumento per le agenzie per il lavoro: copre in fretta le richieste urgenti di personale
operativo, mostrando sul radar i lavoratori compatibili attorno all'azienda cliente e
raccogliendo le risposte in tempo reale.

> Prototipo dimostrativo con dati di prova: nessun database, nessun dato reale.
> Software proprietario, vedi [LICENSE](LICENSE).

## Cosa mostra la demo
- Matching automatico: abilitazioni valide alla data del lavoro, distanza, turno, disponibilità.
- Esclusi spiegati, con il motivo di ciascuno.
- Invio della proposta e risposte simulate (1 secondo = 1 minuto).
- Anteprima del messaggio ricevuto dal lavoratore.
- Nuova richiesta urgente in meno di un minuto.
